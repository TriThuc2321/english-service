# Writing explanations

Students only see `explanation` on the result page, after their attempt has been graded and next to their wrong answers. It should teach them how to find the answer. Restating the key doesn't help.

## Format

Two short paragraphs: English first, then Vietnamese. Each one starts with its label on the same line.

```
EN: <1–3 sentences>
VI: <the same reasoning in natural Vietnamese>
```

- Quote the passage words that decide the answer in the EN part, inside "double quotes", exactly as printed. Repeat that English quote in the VI part, and translate it in brackets only if the meaning isn't obvious. Students need to see the original words in order to spot them in the text.
- Name the location: "Paragraph D", "the second paragraph", "the summary sentence before 21".
- Show the paraphrase link, because that is the skill being tested: question wording ↔ passage wording ("financial success" ↔ "did not make a profit").
- For a wrong option that is a tempting distractor, add one clause saying why it's wrong. Skip this for options nobody would pick.
- Keep it short: about 60 words per language at most. Write the VI part as a Vietnamese teacher would say it, not as a word-for-word translation.
- Don't start with "The answer is X". The student already sees the key. Start with the reasoning.

## By question type

**TRUE / FALSE / YES / NO.** Quote the sentence that agrees or contradicts, then name the contradiction.
**NOT GIVEN.** There is nothing to quote, so say what the passage _does_ say about the topic and what it leaves out. This is the case students find hardest, so be explicit.

```
EN: The passage gives the number of passengers on the first day ("almost 40,000"), but never says how many were expected, so we cannot compare.
VI: Bài chỉ nói số hành khách ngày đầu ("almost 40,000"), không hề nhắc đến con số dự đoán, nên không thể kết luận "nhiều hơn dự kiến".
```

**Completion (notes / summary / sentence / table).** Quote the clause that holds the word, show the grammar fit (noun after "the", plural…), and point out the paraphrase.

```
EN: "the critical articles printed by the press" — "negative articles" paraphrases "critical articles", and the gap after "in the" needs a noun: press.
VI: "critical articles" = "negative articles" (bài báo tiêu cực); chỗ trống sau "in the" cần danh từ → press (báo chí).
```

**Word-bank summary (A–J).** Name the phrase, its letter, and the passage words it paraphrases.
**Matching information.** Quote the sentence in the paragraph that the item describes.
**Multiple choice / Choose TWO.** Justify the correct option or options, then rule out the strongest distractor.

## When not to write one

Write an explanation only when you can ground it in the passage. If the answer depends on something you can't see (audio, an image, a page that didn't render), or you aren't confident why the key is right, leave `explanation` out and list the question number in the report. A missing explanation is better than a wrong one, because a wrong explanation teaches the wrong skill.
